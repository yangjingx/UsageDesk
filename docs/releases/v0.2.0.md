# UsageDesk v0.2.0 · 2026-09-26

## 中文

### 外观与可访问性

- 卡片底色、边框、文字、次要说明和进度轨道改用系统语义颜色，随 macOS 浅色或深色模式自动切换。
- 修复浅色模式下标题卡片选择菜单文字与背景对比度不足的问题；选择菜单改由系统绘制。
- Codex 以中性色和克制的蓝紫色强调展示额度，DeepSeek 使用蓝色强调余额，避免把两个服务混成相同的配色。
- 在 macOS 26 及更新系统上，顶部刷新与设置按钮使用系统玻璃效果；旧系统和开启“减少透明度”时使用普通不透明控件。开启“减少动态效果”时停用装饰性切换动画。
- 用原创双环图形替换旧的柱形应用图标。外环代表 Codex，内环代表 DeepSeek；浅色、深色图形会随应用外观切换。Codex 卡片的旧彩色结形图标改为中性的代码符号，DeepSeek 卡片保留鲸鱼标识。

### 交互与布局修复

- 从卡片空白处拖动时使用屏幕坐标计算窗口位移，修正先前拖动的跳跃和闪烁；松开后保存窗口位置。
- 保留标题和倒三角打开的 Codex/DeepSeek 选择菜单，以及菜单栏中的“切换卡片”和“垂直展开”两种布局。卡片切换使用轻量淡入淡出，尊重系统动态效果设置。
- DeepSeek “可用余额”标签和右侧金额改用垂直居中对齐，修正不同字号造成的明显错位；浅色、深色和不同币种均已检查。
- 顶部刷新与齿轮按钮统一视觉样式；Codex、DeepSeek 卡片继续各自打开对应设置。

### 数据、兼容性与升级

- Codex 继续通过本机 `codex app-server` 的 `account/rateLimits/read` 读取当前账户实际返回的额度窗口；右侧显示**剩余比例**，并非已用比例。不会按 Free、Go、Plus 或 Pro 套餐预设五小时或每周窗口。
- DeepSeek 继续只读取开放平台的 **API 账户余额**，按币种显示余额、赠金和充值构成；不统计 DeepSeek 网页聊天、请求数量或 Token 消耗。
- 保留中英双语、Codex 默认 10 秒与 DeepSeek 默认 60 秒自动刷新、可自定义刷新间隔、始终置顶、手动录入和菜单栏退出。
- 升级沿用原来的本地用量目录与 DeepSeek 钥匙串条目；无需重新输入已有 API Key。安装包不含个人 Cookie、Token、Key 或用量快照。
- 支持 Apple 芯片 Mac，最低 macOS 15。发布包为临时签名，未经 Apple 公证。

### 验证

- 使用虚构 Codex 窗口和 DeepSeek 余额检查浅色、深色、卡片选择菜单、双卡纵向布局与中英文字。
- 在运行中的应用里检查 DeepSeek 金额行对齐，并确认本机安装版能读取现有钥匙串条目与余额。
- 从仓库源码重新构建发布 ZIP，验证包内版本为 `0.2.0`（构建号 `7`）且应用签名有效。

## English

### Appearance and accessibility

- Card surfaces, borders, text, secondary labels, and meter tracks now use system-aware colors and follow macOS Light and Dark Mode.
- Fixed unreadable text in the provider picker under Light Mode by allowing the system to draw the picker surface.
- Codex now uses neutral surfaces with a restrained indigo accent; DeepSeek keeps its own blue balance accent.
- On macOS 26 and later, small refresh and settings controls use system glass. Older systems and Reduce Transparency use ordinary opaque controls. Reduce Motion disables decorative switch animations.
- Replaced the old three-bar app icon with an original double-ring remaining-capacity mark: Codex on the outer ring, DeepSeek on the inner ring. The app swaps light and dark artwork with its appearance. The Codex card uses a neutral code glyph in place of the old colored knot; the DeepSeek whale remains.

### Interaction and layout fixes

- Dragging from empty card space now calculates movement in screen coordinates, addressing the jump and flicker seen during window movement. The card saves its position when released.
- The title and chevron still open the Codex/DeepSeek picker. The menu bar still offers switch-card and vertically stacked layouts. Card changes use a short fade and honor Reduce Motion.
- Centered the DeepSeek available-balance label and amount vertically, fixing the visible mismatch caused by different font sizes. Checked both appearances and multiple currencies.
- Refresh and settings buttons now share the same visual treatment while retaining separate Codex and DeepSeek settings.

### Data, compatibility, and upgrades

- Codex still reads only the quota windows actually returned by the local `codex app-server` `account/rateLimits/read` method. Large figures show **remaining percentages**. The app does not assume that Free, Go, Plus, or Pro accounts all have five-hour or weekly windows.
- DeepSeek still reads **Open Platform API account balance** by currency, including granted and topped-up amounts. It does not measure DeepSeek web chat, request counts, or token use.
- Chinese/English, 10-second default Codex refresh, 60-second default DeepSeek refresh, custom intervals, always-on-top, manual entry, and menu bar quit remain available.
- Upgrades keep the existing local usage folder and DeepSeek Keychain item, so an existing API key need not be entered again. The ZIP contains no user's cookies, tokens, keys, or usage snapshots.
- Requires an Apple silicon Mac with macOS 15 or later. The release is ad hoc signed and not notarized by Apple.

### Verification

- Checked Light and Dark Mode, the title picker, stacked cards, and Chinese/English text with fictional Codex and DeepSeek data.
- Checked the balance row in the running app and confirmed that the installed build reads the existing Keychain item and balance.
- Rebuilt the ZIP from repository source, verified version `0.2.0` (build `7`), and verified the app signature.
